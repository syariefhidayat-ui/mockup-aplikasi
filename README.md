# 🎸 Chord Gitarku

Aplikasi pembelajaran Chord Gitar interaktif yang dirancang khusus untuk membantu pemula menguasai gitar dengan lebih mudah dan menyenangkan.

## ✨ Fitur Utama
* 🔍 **Pencarian Cepat:** Cari berbagai macam chord gitar dalam hitungan detik.
* 📂 **Kategori Chord:** Filter berdasarkan tipe chord (Major, Minor, Seventh, Suspended).
* 🖼️ **Diagram Visual:** Tampilan diagram fretboard yang jelas dengan penomoran posisi jari.
* 💡 **Tips Bermain:** Instruksi tambahan dan tips teknik menekan senar yang benar.
* ❤️ **Favorit:** Simpan chord yang sedang kamu pelajari ke daftar favorit.
* 🌐 **Multi-bahasa:** Mendukung Bahasa Indonesia.

## 🛠️ Tech Stack (Rencana Pengembangan)
* **Framework:** Flutter / React Native (Mobile)
* **State Management:** Provider / Redux
* **Database:** LocalStorage / SQLite
* **AI Integration:** Chord Recognition using Audio Input (Bulan Juni-Juli)
